# Частная скорая помощь (Бишкек) — сайт

Одностраничный сайт частной скорой помощи в Бишкеке (ул. Исакеева, 32/2) со встроенной, временно отключённой панелью управления.

## Особенности

- Весь контент правится через админку: тексты, услуги, шаги работы, цены, оснащение, отзывы, вопросы, новости, контакты, название и цвет акцента
- Мигалка на фоне первого экрана (красный и синий свет), отключается в админке
- Заявки с формы попадают в раздел «Заявки» со статусами новая / в работе / выполнена
- Адаптивная вёрстка, закреплённая кнопка вызова на телефоне
- Разметка schema.org, мета-теги, sitemap
- Ни сборки, ни npm, ни зависимостей: один HTML-файл

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Админ-панель временно отключена: кнопка, ссылка и вход по `#admin` убраны, панель скрыта. Код панели остался в файле, чтобы её можно было вернуть — для этого удалите правило `#admin,#admin.on{display:none!important}` и атрибут `hidden` у кнопки `#adminBtn` и ссылки `#adminLink`.

## Как сейчас хранятся данные

На обычном хостинге правки и заявки сохраняются в браузере того, кто их внёс (localStorage). Это значит:

- посетители видят содержимое, заданное в коде по умолчанию, а не ваши правки
- заявки видны только на том устройстве, с которого их отправили
- админка открыта любому, кто знает адрес

Для боевой работы нужен сервер. Минимальный рабочий вариант описан ниже.

## Что доделать для боевой версии

1. **База данных.** Контент и заявки хранить на сервере: MySQL или PostgreSQL, либо готовая CMS (WordPress, Strapi, Directus).
2. **API.** Два метода: отдать контент сайту и сохранить правки из админки. Подойдёт PHP на обычном хостинге, Node.js или Laravel.
3. **Авторизация.** Логин и пароль для диспетчеров и администратора, пароли хранятся хешированными, сессии по HTTPS. Сейчас админка ничем не закрыта.
4. **Уведомления о заявках.** Дублировать новые заявки в Telegram (Bot API) или на почту, чтобы диспетчер видел их сразу.
5. **Резервные копии** базы и файлов.

Где в коде подключать сервер: найдите функции `LS.load` и `LS.save`, а также обработчик кнопки «Сохранить» — замените обращения к localStorage на запросы к вашему API.

## Доступность

Мигание фона отключается автоматически, если у посетителя в системе включено уменьшение анимаций. Это важно: резкие световые пульсации могут быть опасны при светочувствительной эпилепсии. Не повышайте яркость и частоту без необходимости.

## SEO после публикации

1. Замените `example.kg` в `robots.txt` и `sitemap.xml` на свой домен.
2. Добавьте сайт в Google Search Console, отправьте sitemap.
3. Заведите карточки в Google Business Profile, 2ГИС и Яндекс Картах — для запросов вроде «скорая помощь Бишкек» они работают сильнее самого сайта.
